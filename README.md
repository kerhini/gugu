# JukeboxBoat (Paper / Purpur 1.21.1 - 1.21.11)

Плагин для Minecraft (Paper / Purpur 1.21.1–1.21.11), добавляющий **Лодки с Музыкальным блоком (Jukebox Boat)** с поддержкой стриминга музыки через **Mixer Reloaded** и **Simple Voice Chat**.

---

## 🌟 Особенности

- 🚤 **Лодка-проигрыватель**: 3D-модель музыкального блока (`BlockDisplay`) жёстко зафиксирована на корме лодки, как сундук в сундучной лодке.
- 🎵 **Непрерывное звучание**: Музыка играет постоянно от самой лодки — плывёте вы на ней, стоите на берегу или причалили.
- 📡 **Интеграция с Mixer Reloaded**: Поддержка воспроизведения треков из интернета (YouTube, SoundCloud, прямые ссылки MP3) через голосовой чат Simple Voice Chat.
- 🎨 **Кастомный 3D-эффект**: Вместо обычных нот из проигрывателя плавно вылетает светящийся 3D-символ (полностью прозрачный, без рамок и фонов).
- 🎮 **Интуитивное управление**:
  - **ПКМ с пластинкой** — вставить / заменить пластинку.
  - **Shift + ПКМ** — извлечь пластинку и остановить музыку.
  - **Обычный ПКМ** — сесть за вёсла лодки.
- 🔨 **Рецепты крафта**: Любая лодка + Музыкальный блок (Jukebox).

---

## ⚙️ Сборка проекта

```bash
./gradlew clean build
```

Готовый JAR-файл появится в `build/libs/JukeboxBoat-1.21.11.jar`.
